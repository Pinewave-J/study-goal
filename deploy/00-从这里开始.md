# 从这里开始 · 学习目标管理台部署包

一句话：把 `index.html` 这一个文件丢到任意静态托管上就能用，**不需要服务器、不需要数据库、不需要登录**。

---

## 一、三种发布方式，挑一个

| 方式 | 耗时 | 需要 Git | 适合 |
|---|---|---|---|
| **Netlify Drop**（推荐先试） | 约 30 秒 | 否 | 只想马上拿到一个链接 |
| **GitHub Pages** | 约 3 分钟 | 是 | 想要稳定长期、可回滚的链接 |
| **本地双击打开** | 0 秒 | 否 | 自己一个人用，不分享 |

### 方式 1：Netlify Drop（最快）

1. 打开 https://app.netlify.com/drop
2. 把本文件夹直接**拖进**虚线框（不用选文件，整个文件夹拖）
3. 等几秒，会得到一个 `https://xxxxxx.netlify.app` 链接
4. 打开链接 → 首次会自动写入 3 个示例目标，能正常打卡即为成功

> 想换域名：站点设置里 `Domain management → Options → Edit site name`，改成比如 `study-goal-songtao`，链接就变成 `https://study-goal-songtao.netlify.app`。

### 方式 2：GitHub Pages

```bash
cd 本文件夹
git init
git add .
git commit -m "学习目标管理台"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后进仓库：`Settings → Pages → Source` 选 `main`、目录选 `/ (root)`，保存。
约 1 分钟后得到 `https://<用户名>.github.io/<仓库名>/`。

> 后续更新：改完 `index.html` 再 `git add . && git commit -m "更新" && git push`，Pages 会自动重发。

### 方式 3：本地直接用

双击 `index.html` 即可。数据同样正常读写，只是这个链接只有你自己能打开。

## 二、先弄清楚：数据存在哪

**存在打开页面的那台设备的浏览器里（localStorage），不在服务器上。**

- ✅ 刷新、关机、关浏览器 —— 数据都在
- ✅ 每个人打开同一个链接，各自看到自己的数据，互不干扰
- ❌ 换手机、换浏览器、清理浏览数据 —— 数据会丢
- ❌ 手机和电脑之间**不会自动同步**

所以每次改完页面要提醒自己：**定期导出备份**。
入口在 App 内「我的 → 备份与迁移 → 导出备份（JSON）」，会下载一个 JSON 文件；
换设备时在新设备上用「从备份导入」恢复（导入会覆盖，先导出留底）。

## 三、和原来那个线上版有什么不同

| | 线上版（WorkBuddy 资料库） | 本部署包 |
|---|---|---|
| 数据存储 | 云端资料库，多设备同步 | 本机浏览器 localStorage |
| 是否需要登录 | 未登录只能看，不能写 | 不需要，打开即可写 |
| 托管位置 | WorkBuddy 平台 | GitHub Pages / Netlify / 本地 |
| 数据备份 | 平台侧负责 | **需要自己导出 JSON** |
| 界面与功能 | 11 个 Tab、打卡/补记/周报/热力图 | **完全一致** |

功能没有任何删减。差异只在「数据存哪儿」。

## 四、首次打开后建议做的两件事

1. **清空示例数据**：`我的 → 数据管理 → 清空示例数据`，然后建自己的目标
2. **加个备份提醒**：每月导出一次 JSON，丢网盘或发自己邮箱

## 五、出问题先看这里

| 现象 | 原因 / 处理 |
|---|---|
| 打开是一片空白 | 浏览器禁用了 localStorage（隐私模式下常见），换普通窗口 |
| 打卡提示「当前环境无数据服务」 | 说明适配器没加载上，确认打开的是**本包的 index.html**，不是旧版页面 |
| 示例数据删了又冒出来 | 只有「三张表全空」时才会重新灌示例，属预期；先建一个自己的目标就不会再出现 |
| 更新了页面但看到的还是旧的 | 强制刷新：`Ctrl + F5`（手机端清一次缓存） |
| 换设备后数据没了 | 属预期行为，用备份 JSON 导入恢复 |

## 六、包里都有什么

| 文件 | 用途 |
|---|---|
| `index.html` | **页面本体**，单文件、零外部依赖，部署只需要它 |
| `README.md` | 技术说明（适配器原理、字段结构），给开发者看 |
| `netlify.toml` | Netlify 部署配置（禁缓存 + 安全响应头），拖部署时可不管 |
| `.gitignore` | Git 提交时的忽略规则 |
| `.nojekyll` | 告诉 GitHub Pages 别用 Jekyll 处理，提交时一并带上 |
